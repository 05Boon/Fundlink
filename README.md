# FundLink

FundLink is an Android application designed for managing student funding opportunities and applications.

## Setup Steps

1. Open the project in Android Studio.
2. Ensure Kotlin KSP and Room dependencies sync cleanly.
3. Build and run the app on an Android Emulator or physical device.
